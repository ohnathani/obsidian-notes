## 2. Describing and Representing Sets

### What is a Set?
*   **Definition:** A **set** is a collection of well-defined objects [2].
*   **Elements:** The objects belonging to a set are called its **elements** [2].
    *   **Notation:** 
        *   $x \in A$ denotes that $x$ is an element of set $A$ [2].
        *   $y \notin A$ denotes that $y$ is not an element of set $A$ [2].

### Methods of Describing Sets
There are two primary methods used to specify set membership:

1.  **Roster (List) Method [3]:**
    *   Elements are explicitly listed/enumerated, separated by commas, and enclosed in curly braces $\{ \}$ [3].
    *   *Example:* $V = \{a, e, i, o, u\}$
    *   **Crucial Rule:** The elements listed in a roster must be **distinct**! [3] Changing the order of listed elements or repeating them does not alter the mathematical set.
2.  **Rule (Set-Builder) Method [3]:**
    *   Elements are not listed individually [3]. Instead, membership is defined by stating a descriptive phrase or predicate $P(x)$ that gives the common property uniquely characterizing the elements [3].
    *   *Example:* $A = \{x \in \mathbb{Z} \mid 1 \le x \le 5\}$
    *   *Note:* While there are some sets that cannot be described using the rule method, it can always be used as long as a common characterizing property exists [3, 4].

## 3. Types and Classifications of Sets

The lecture slides define nine fundamental types and classifications of sets [4]:

### 1. Empty Set (Null or Void Set)
*   A set having **no elements** [4].
*   **Notation:** Denoted by $\emptyset$ or $\{\}$ [4].
*   *Note:* The notation $\{\emptyset\}$ represents a singleton set containing the empty set, which is *not* empty ($|\{\emptyset\}| = 1$).

### 2. Finite and Infinite Sets
*   Sets are classified by size [4]:
    *   **Finite Set:** A set is finite if it is possible to write down a complete, exhaustive list of all its elements [5].
    *   **Infinite Set:** A set that is not finite (it contains an uncountable or infinite number of elements, making a complete roster list impossible) [5].
*   **Cardinality ($|A|$):** The number of elements in a finite set $A$ is called its cardinality, denoted by $|A|$ [5].

### 3. Equivalent Sets ($\approx$)
*   Sets $A$ and $B$ are equivalent if and only if there exists a **one-to-one correspondence** (bijection) between them [5].
*   **Notation:** If $A$ and $B$ are equivalent, we write:
    $$A \approx B$$ [5]
*   *Implication:* For finite sets, equivalent sets share the same cardinality ($|A| = |B|$).

### 4. Subset ($\subseteq$)
*   Set $A$ is a subset of $B$ if and only if each element of $A$ is also a member of $B$ [5].
*   **Notation:** If $A$ is a subset of $B$, we write:
    $$A \subseteq B$$ [5]

### 5. Proper Subset ($\subset$)
*   If $A$ is a subset of $B$ ($A \subseteq B$) and there is at least one element of $B$ which is not an element of $A$, then $A$ is a **proper subset** of $B$ [6].
*   **Notation:** If $A$ is a proper subset of $B$, we write:
    $$A \subset B$$ [6]

### 6. Equal Sets ($=$)
*   Two sets $A$ and $B$ having the exact same elements are equal [6].
*   **Notation:** If $A$ is equal to $B$, we write $A = B$ [6].
*   **Double Inclusion Theorem:** Observe that $A = B$ if and only if $A$ is a subset of $B$ and $B$ is a subset of $A$:
    $$A = B \iff (A \subseteq B \land B \subseteq A)$$ [6, 14]

### 7. Power Set ($\mathcal{P}(A)$ or $P^A$)
*   The set whose elements are all the subsets of set $A$ is called the power set of $A$ [6].
*   **Notation:** Denoted by $P^A$ or $\mathcal{P}(A)$ [6].
*   *Cardinality Rule:* If $|A| = n$, then $|\mathcal{P}(A)| = 2^n$.

### 8. Universal Set ($U$)
*   A fixed context set that contains all sets under discussion in a given problem is called the universal set [6].
*   **Notation:** Denoted by $U$ [7].

### 9. Cartesian Product ($A \times B$)
*   Let $A$ and $B$ be sets. The Cartesian product of $A$ and $B$, denoted by $A \times B$, is the set of all ordered pairs $(a, b)$ where $a \in A$ and $b \in B$ [7].
    $$A \times B = \{(a, b) \mid a \in A \land b \in B\}$$ [7]
*   **Crucial Non-Commutativity Note:** Cartesian products $A \times B$ and $B \times A$ are **not equal**, unless $A = \emptyset$ or $B = \emptyset$ or $A = B$ [8].

### Exercise 2: Cartesian Product [8]
Give the Cartesian products and cardinality of $A \times B$ and $B \times A$ where:
$$A = \{0, 1, 2, 3\} \quad \text{and} \quad B = \{x, y, z\}$$ [8]

#### Solution:
1.  **$A \times B$:** Pairs $(a, b)$ where $a \in A$ and $b \in B$:
    $$A \times B = \{(0,x), (0,y), (0,z), (1,x), (1,y), (1,z), (2,x), (2,y), (2,z), (3,x), (3,y), (3,z)\}$$
2.  **$B \times A$:** Pairs $(b, a)$ where $b \in B$ and $a \in A$:
    $$B \times A = \{(x,0), (x,1), (x,2), (x,3), (y,0), (y,1), (y,2), (y,3), (z,0), (z,1), (z,2), (z,3)\}$$
3.  **Cardinality:**
    *   $|A| = 4$ and $|B| = 3$.
    *   $|A \times B| = |A| \cdot |B| = 4 \cdot 3 = 12$ [8].
    *   $|B \times A| = |B| \cdot |A| = 3 \cdot 4 = 12$ [8].

## 5. Operations on Sets

The lecture defines five core set operations [8]:

### 1. Complement ($A'$ or $A^c$)
*   The set of elements in the universal set $U$ which are not in $A$ [8].
    $$A^c = \{x \in U \mid x \notin A\}$$
*   **Properties of the Complement [8]:**
    *   $\emptyset^c = U$ [8]
    *   $U^c = \emptyset$ [8]
    *   $(A^c)^c = A$ [8, 10]

### 2. Set Difference ($B - A$)
*   Also called **"B but not A"**, it is the set of elements in $B$ which are not elements of $A$ [8].
    $$B - A = \{x \mid x \in B \land x \notin A\}$$ [14]
*   **Properties of Set Difference [8]:**
    *   $U - A = A^c$ [8]
    *   $A - \emptyset = A$ [8]
    *   $A - A = \emptyset$ [8]

### 3. Set Union ($A \cup B$)
*   The set of elements in $A$ or in $B$ (or both) [9].
    $$A \cup B = \{x \mid x \in A \lor x \in B\}$$ [14]
*   **Properties of Set Union [9]:**
    *   $A \cup B = B \cup A$ (Commutative) [9, 10]
    *   $(A \cup B) \cup C = A \cup (B \cup C)$ (Associative) [9, 10]

### 4. Set Intersection ($A \cap B$)
*   The set of elements that are common to both $A$ and $B$ [9].
    $$A \cap B = \{x \mid x \in A \land x \in B\}$$ [14]
*   **Disjoint Sets:** Two sets $A$ and $B$ are disjoint if and only if they share no common elements [9]:
    $$A \cap B = \emptyset$$ [9]

### 5. Other Operations
*   **Symmetric Difference ($A \Delta B$ or $A \oplus B$):** The set of elements belonging to exactly one of the sets [14].
    $$A \Delta B = \{x \mid \text{exactly one of } x \in A \text{ and } x \in B \text{ is true}\}$$ [14]
    $$A \Delta B = (A - B) \cup (B - A) = (A \cup B) - (A \cap B)$$

## 6. Algebraic Laws of Set Operations

The lecture details the standard set identities used to simplify expressions and prove equalities [9, 10]:

| Name of Law | Union Statement | Intersection Statement |
| :--- | :--- | :--- |
| **Idempotent Laws** [9, 10] | $A \cup A = A$ [10] | $A \cap A = A$ [10] |
| **Commutative Laws** [10] | $A \cup B = B \cup A$ [10] | $A \cap B = B \cap A$ [10] |
| **Associative Laws** [10] | $A \cup (B \cup C) = (A \cup B) \cup C$ [10] | $A \cap (B \cap C) = (A \cap B) \cap C$ [10] |
| **Distributive Laws** [9, 10] | $A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$ [10] | $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$ [10] |
| **Identity Laws** [9, 10] | $A \cup \emptyset = A$ [10] | $A \cap U = A$ [10] |
| **Domination / Null Laws** [9, 10] | $A \cup U = U$ [10] | $A \cap \emptyset = \emptyset$ [10] |
| **Inverse / Complement Laws** [9, 10] | $A \cup A^c = U$ [10] | $A \cap A^c = \emptyset$ [10] |
| **Absorption Laws** [9, 10] | $A \cup (A \cap B) = A$ [10] | $A \cap (A \cup B) = A$ [10] |
| **De Morgan’s Laws** [9, 10] | $(A \cup B)^c = A^c \cap B^c$ [10] | $(A \cap B)^c = A^c \cup B^c$ [10] |
| **Double Complement (Involution)** [9, 10]| $(A^c)^c = A$ [10] | |
| **0/1 Laws** [8] | $\emptyset^c = U$ [8] | $U^c = \emptyset$ [8] |

## 7. Methods of Proving Set Equality

The lecture notes outline **five different methods** to prove theorems and equalities on sets [11, 12]:

1.  **Proof using previously proven theorems:** Applying algebraic identities sequentially to simplify one side of an equation to match the other [11].
2.  **Indirect Method / Contradiction:** Assuming the conclusion is false and showing that this leads to a logical contradiction [11, 12].
3.  **Proof using Venn Diagrams:** Drawing and shading both sides of the statement on separate Venn diagrams to show that they yield identical shaded patterns [11, 12].
4.  **Proof using Set-membership Tables:** Constructing a binary table for an arbitrary element $u \in U$ [12]. We assign:
    *   **$1$** if $u$ is a member of the set ($u \in X$) [12].
    *   **$0$** if $u$ is not a member of the set ($u \notin X$) [12].
    *   If the truth value columns for both sides of the set statement match under all configurations, the equality is proven [12].
5.  **Disproof by Counterexample:** Disproving a false theorem by presenting a specific example of sets that violates the statement [11, 12].

### Algebraic Equality Proof Exercises [14]

#### Exercise 1: Show that $(B - A) \cup (C - A) = (B \cup C) - A$ [14]
$$\begin{align*}
\text{LHS} &= (B - A) \cup (C - A) \\
&= (B \cap A^c) \cup (C \cap A^c) \quad &&\text{[Set Difference Identity: } X - Y = X \cap Y^c\text{]} \\
&= (B \cup C) \cap A^c \quad &&\text{[Distributive Law in Reverse]} \\
&= (B \cup C) - A \quad &&\text{[Set Difference Identity]} \\
&= \text{RHS} \quad \blacksquare
\end{align*}$$

#### Exercise 2: Show that $(A - B) - (B - C) = A - B$ [14]
$$\begin{align*}
\text{LHS} &= (A - B) - (B - C) \\
&= (A \cap B^c) \cap (B \cap C^c)^c \quad &&\text{[Set Difference Identity]} \\
&= (A \cap B^c) \cap (B^c \cup (C^c)^c) \quad &&\text{[De Morgan's Law]} \\
&= (A \cap B^c) \cap (B^c \cup C) \quad &&\text{[Double Complement Law]} \\
&= A \cap [B^c \cap (B^c \cup C)] \quad &&\text{[Associative Law]} \\
&= A \cap B^c \quad &&\text{[Absorption Law: } X \cap (X \cup Y) = X\text{]} \\
&= A - B \quad &&\text{[Set Difference Identity]} \\
&= \text{RHS} \quad \blacksquare
\end{align*}$$

#### Exercise 3: Show that $[(A - B) - (B - C)]' = A' \cup B$ [14]
From Exercise 2, we know that $(A - B) - (B - C) = A - B$. Let's substitute this simplified expression directly:
$$\begin{align*}
\text{LHS} &= [(A - B) - (B - C)]^c \\
&= (A - B)^c \quad &&\text{[Using LHS Simplification from Ex 2]} \\
&= (A \cap B^c)^c \quad &&\text{[Set Difference Identity]} \\
&= A^c \cup (B^c)^c \quad &&\text{[De Morgan's Law]} \\
&= A^c \cup B \quad &&\text{[Double Complement Law]} \\
&= \text{RHS} \quad \blacksquare
\end{align*}$$

## 8. General Theorems on Sets

The lecture details several structural theorems regarding subsets, empty sets, and logical equivalences:

### Transitivity of Subset Relations [13]
Let $A, B, C \subseteq U$. The following transitivity properties hold [13]:
*   **a)** If $A \subseteq B$ and $B \subseteq C$, then $A \subseteq C$ [13].
*   **b)** If $A \subset B$ and $B \subseteq C$, then $A \subset C$ [13].
*   **c)** If $A \subseteq B$ and $B \subset C$, then $A \subset C$ [13].
*   **d)** If $A \subset B$ and $B \subset C$, then $A \subset C$ [13].

### Empty Set Properties [13]
For any universal set $U$, let $A \subseteq U$. Then:
*   $\emptyset \subseteq A$ (The empty set is a subset of every set) [13].
*   If $A \neq \emptyset$, then $\emptyset \subset A$ (The empty set is a proper subset of every nonempty set) [13].

### Equivalent Conditions for $A \subseteq B$ [13]
For any universe $U$, and sets $A, B \subseteq U$, the following four statements are logically equivalent [13]:
1.  $A \subseteq B$ [13]
2.  $A \cap B = A$ [13]
3.  $A \cup B = B$ [13]
4.  $B^c \subseteq A^c$ [13]

## 9. Partition of a Set

### Definition of a Partition
A **partition** of a set is a grouping of the set's elements into non-empty subsets in such a way that every element is included in one and only one of the subsets [14].

### Mathematical Conditions for a Partition
A collection of nonempty sets $\{A_1, A_2, \dots, A_n\}$ is a valid partition of a set $A$ if and only if [14]:
1.  **Exhaustive Union:** Their union equals the original set:
    $$A = A_1 \cup A_2 \cup \dots \cup A_n$$ [14]
2.  **Mutually Disjoint:** Every pair of distinct subsets shares no elements:
    $$A_i \cap A_j = \emptyset \quad \text{for all } i \neq j$$ [14]

### Partition Exercise [15]
*   **Statement:** Verify if the set of even integers and the set of odd integers form a partition of the set of integers ($\mathbb{Z}$) [15].
*   **Proof / Verification:**
    Let $E = \{x \in \mathbb{Z} \mid x \text{ is even}\}$ and $O = \{x \in \mathbb{Z} \mid x \text{ is odd}\}$.
    1.  **Non-emptiness:** Both $E \neq \emptyset$ and $O \neq \emptyset$ (e.g., $2 \in E$ and $1 \in O$).
    2.  **Exhaustive Union:** Every integer is either even or odd, so $E \cup O = \mathbb{Z}$.
    3.  **Mutual Disjointness:** No integer can be both even and odd, so $E \cap O = \emptyset$.
    *   **Conclusion:** Therefore, $\{E, O\}$ is a valid partition of the set of integers $\mathbb{Z}$ [15].
